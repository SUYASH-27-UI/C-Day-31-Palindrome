# C Day 31 - Palindrome Number

This program checks whether a number is a palindrome or not.

## Example

Input:
121

Output:
Palindrome Number

Input:
123

Output:
Not a Palindrome Number

## Concepts Used

- while loop
- if-else
- Modulus Operator (%)
- Division (/)
- Number Reverse
- Comparison
